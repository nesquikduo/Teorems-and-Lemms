Программа предназначена для автоматического извлечения теорем и лемм из научных PDF-документов. 
Дополнительно программа определяет название статьи и авторов при помощи локальной нейросетевой модели Qwen, запущенной через Ollama.

Возможности программы

- чтение PDF-документов;
- поиск теорем и лемм;
- извлечение текста математических утверждений;
- определение названия статьи;
- определение авторов статьи;
- сохранение результата в JSON-файл.

Используемые технологии

- Python
- PyMuPDF
- requests
- Ollama
- Qwen 2.5

Установка библиотек

Перед запуском программы необходимо установить зависимости:

pip install pymupdf requests

Установка Ollama

Скачать Ollama можно с официального сайта:

https://ollama.com/download

После установки необходимо скачать модель:

ollama pull qwen2.5:3b

Подготовка файлов

Создайте папку:

pdf_files

Поместите в неё PDF-документы для обработки.


Запуск программы

Запуск выполняется командой:

python __main__.py

Результат работы

После выполнения программы будет создан файл:

result.json

Особенности работы

- программа работает только с PDF-файлами;
- модель Qwen запускается локально через Ollama;
- поиск выполняется по словам «Теорема» и «Лемма»;
- результат сохраняется в формате JSON.
