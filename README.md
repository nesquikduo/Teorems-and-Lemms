## Theorem & Lemma Extractor

Программа для автоматического извлечения теорем и лемм из научных PDF-статей. Для определения названия статьи и авторов используется локальная языковая модель Qwen через Ollama. Результат сохраняется в файл result.json.


---


## Что делает программа

-  Находит все PDF-файлы в папке pdf_files. 
-  Извлекает текст из документов с помощью PyMuPDF.
-  Определяет название статьи по первой странице.
-  Определяет авторов статьи по первой странице.
-  Находит теоремы и леммы в тексте.
-  Сохраняет номер страницы найденного фрагмента.
-  Сохраняет начальный и конечный индексы найденного блока.
-  Формирует итоговый файл result.json.


---


## Требования

-  Python 3.8+
-  Ollama
-  Модель qwen2.5:3b
-  Библиотеки:
    -  pymupdf
    -  requests


---


## Быстрый старт

**1. Установите зависимости**

```
pip install pymupdf requests
```

**2. Установите Ollama**

Скачайте Ollama с официального сайта: https://ollama.com/download

**3. Загрузите модель**

```
ollama pull qwen2.5:3b
```

**4. Подготовьте PDF-файлы**

Создайте папку:

*pdf_files* и поместите в неё статьи для обработки.

**5. Запустите программу**

python *__main__.py*

**6. Получите результат**

После завершения работы будет создан файл:

*result.json*


---


## Формат результата

Для каждой найденной теоремы или леммы сохраняются:

-  название статьи;
-  авторы;
-  номер страницы;
-  тип фрагмента (theorem или lemma);
-  текст фрагмента;
-  начальный индекс;
-  конечный индекс.
